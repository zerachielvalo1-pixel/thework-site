# DESIGN.md — The Work

## Identity
The Work. Official student publication of Tarlac State University. Founded 1948.
78th Generation (2025–2026). Broadsheet heritage, digital-native delivery.
Permanent home for every article, release, video, and board the paper has produced.

## Personality
Serious, civic, independent, unafraid. Progressive student journalism.
Filipino university newsroom, not a startup. Voice: reporter's clarity, manifesto's conviction.

## Audience
TSU students, faculty, alumni. Philippine student-journalism readers. Mobile-heavy,
mixed network, mixed device age.

## Typography
Headlines + body: Merriweather (serif). Newspaper-adjacent, legible at small sizes on phones.
UI + meta + labels: Merriweather Sans. Sibling face, keeps the family coherent.
No monospace by default. Only inside code samples in the admin.

## Radius
Base 6px (buttons, inputs, small cards)
Large 12px (panels, modals, feature cards)
Pill reserved for chips, tabs, category labels
Circular for icon buttons, avatars, save button

## Motion
prefers-reduced-motion respected globally
Scroll-reveal: single fade + translateY(14px)
Hover: translateY(-1 to -3px) + border/shadow change
Carousel: 8s Ken Burns on active slide
No bounce. No scale on every element.

## Dials
ENERGY 2 / RHYTHM 2 / MOTION 1
ENERGY 2 — masthead, bold serif headlines, active sort/filter; not Awwwards-loud
RHYTHM 2 — hero + sidebar + more-stories + section previews + CTA band; varied but predictable
MOTION 1 — one animation, hover feedback only, reduced-motion honored
