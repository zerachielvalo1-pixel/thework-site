# The Work site audit 004

Date: 2026-10-21
Scope: focused review of the site logo and favicon after the reported mismatch.

## Finding

### 1. HIGH, R-20 and R-23: Browser favicon uses a placeholder W instead of the official mark

Evidence:

- `public/index.html:51` defines the favicon as an inline SVG containing a single `W`.
- `public/404.html:9` repeats the same placeholder favicon.
- `public/icon-192.png` and `public/icon-512.png` already contain the official The Work feather and open-book mark used by the PWA manifest.
- The attached screenshot shows the placeholder W favicon rather than the official mark.

Impact: the browser tab and standalone error page do not use the publication's actual identity, even though the correct logo assets are already in the repository.

Smallest useful correction: replace both inline W favicon declarations with the existing `icon-192.png` asset, keeping the current manifest icons unchanged.

One-line rule reason: R-20 requires the interface to carry the publication's real visual identity, and R-23 requires an existing approved asset to be used instead of an invented placeholder.
