# The Work backend and permissions audit 006

Date: 2026-10-21
Scope: comparison of the supplied Supabase role and egress context with the current frontend and Worker implementation.

## Findings approved for correction

1. Board photo uploads bypass `/api/upload-thumb` and write directly to Supabase Storage.
2. `ROLE_PERMISSIONS.users` says EB is denied while `canAccess('users')` correctly grants EB access.
3. Shared-account identity selection is used for attribution but not for member dashboard matching.
4. Destructive and staff-management client methods rely too heavily on hidden navigation instead of defense-in-depth role checks.
5. The application has no Service Role Key path, so the documented Dev RLS bypass is not implemented. Preserve the safe publishable-key model and make the limitation explicit rather than exposing a secret.
